原始方案随本地 Git 保存。Windows 10 LTSC x64 已安装 Python 3.12.7；Realtek USB 网卡「以太网 3」实测 Up / 100 Mbps。现场确认 EK1100 → EL3104 → EL4134 → EL9011 端盖，20 V 供电，AO1/4 分别双线接 AI1/4，通道 2/3 悬空。

百兆物理链路已确认。设备身份、OP、模拟量电压和拔线归零以实机报告为准。
