# 现场验收

## 测点与零点

万用表直流电压。EL4134 AO1 红 1、黑 2，AO4 红 7、黑 8。用户在零指令期间测得 AO1 −0.9 mV、AO4 −0.5 mV。记录只描述现场零点，增益与偏移参数可编辑，展示仍采用设备的原始量程换算。

## 通信

现场 20 V，Realtek USB「以太网 3」协商 100 Mbps。Npcap 1.90 与 PySOEM 1.1.13 发现三个 Beckhoff 从站，全部进入 OP，AL 状态码 0。

| 从站 | 产品码 | Revision |
|---|---|---|
| EK1100 | 0x044C2C52 | 0x00120000 |
| EL3104 | 0x0C203052 | 0x00140000 |
| EL4134 | 0x10263052 | 0x03FD0000 |

EL3104 映射为四组 16 位状态和 16 位有符号输入。EL4134 映射为四组 16 位有符号输出，默认替代值为零。预计 WKC 3。SM2 控制字在运行配置中由 0x24 设为 0x64，回读 100 ms 过程数据看门狗。扫描详情位于 `logs/scan.json`。零输出通信的验收时长由用户调整为 180 秒。

首次长测完成 600 秒，交换 58,517 个周期，WKC 失配 0，三个从站保持 OP，退出时零值 WKC 确认成功。首次统计使用 Windows 毫秒粒度计时，后续改用高分辨率时钟。

复测 180.004 秒，17,991 个周期，WKC 失配 0，三个从站保持 OP。周期中位数 10.007 ms，P95 10.668 ms，最长 38.332 ms。退出时已收到零值过程数据确认。详情见 `logs/zero-soak.json`。

## 回环与故障

- AO1、AO4 分别执行 0、+0.5、+1、0、−0.5、−1、0 V。输入回读与指令的最大偏差分别是 0.005 V、0.002 V。另一条回环在对应的单路阶跃中保持近零。
- 0.2 Hz 正弦指令峰值 0.800 V。AI1 实测范围 -0.803 至 0.797 V，AI4 为 -0.801 至 0.8 V。
- 一次实机观察期间出现 WKC 1/3。输出被锁定，输入标为失效，网页显示输出状态未知。网卡复查为 Up / 100 Mbps，用户确认未动网线和电源。故障原因未定位。上述 180 秒复测在该事件后完成，手动重连保持输出锁定。
- Edge 与 EGO 的模拟和实机页面均已验证，包含 CSV、校准参数持久化和控制权互斥。

用户在 AO1 指令 +500 mV 时用万用表测得 +498.5 mV，误差 −1.5 mV。测试后 AO1 清零，再切换至 AO4。
用户在 AO4 指令 +500 mV 时用万用表测得 +499.3 mV，误差 −0.7 mV。

AO4 +500 mV 保持期间拔下 Realtek USB 网卡网线。Windows 链路断开，网页收到 WKC −1/3（没有收到该周期的回应），切换到故障，输入无效，输出锁定。
拔线后用户在 AO4 端子 7–8 测得 −0.5 mV，与零指令基线一致。断线归零通过。万用表读数用于验证稳态归零，未测量实际归零耗时。
插回后网卡重新建立 100 Mbps 链路。仪表盘手动重连后三个从站进入 OP，WKC 3/3，四路指令为零，输出仍锁定。

故障恢复另外覆盖模拟模式关闭控制页和通信工作进程意外退出。Edge 验证会话释放后撤销输出，以及工作进程退出后显示故障、锁定输出和输入失效。
