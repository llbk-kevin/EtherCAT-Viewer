# 四、通信诊断与故障排查

## 一、先看设备状态和 WKC

EtherCAT 从站随配置由 INIT、PREOP 到 SAFEOP，最终到 OP。OP 表示进入正常过程数据交换状态。AL 状态码提供设备报告的详细原因，健康现场为 `0x0000`。

**WKC（Working Counter，工作计数器）** 是过程数据报文的处理回执。主站发送一轮数据，相关设备处理读写后改动该计数器。`3/3` 表示实际值与这套 PDO 映射计算出的预期值一致；预期值取决于报文读写组合和配置。`1/3` 表示这一轮只收到部分处理回执；`−1/3` 表示主站没有收到该轮回应。仅靠 WKC 无法定位哪片端子或哪根线出错。AO 端实测电压需由万用表或接好的 AI 回读确认。

## 二、区分周期、收发耗时和遗漏

| 指标 | 含义 |
| --- | --- |
| 目标周期 | 请求的主站调度间隔，默认 10 ms |
| 实际周期间隔 | 连续两轮发送开始时刻的差 |
| 主站收发耗时 | 一轮发送开始到接收返回的时间 |
| 实际更新率 | 用统计窗内的间隔计算平均每秒交换次数 |
| 通信异常 | 例如 WKC 失配、退出 OP |
| 调度漏期 | 工作进程超过了多少已有的调度时点 |
| 遥测与本页推送遗漏 | 后台队列或 WebSocket 客户端积压时略过的数据量 |

页面给出近 10 秒最新值、中位数、P95、最大值与样本数。P95 是约 95% 测量值落在其下的阈值。Windows 调度和网卡会影响时序。1 ms 是可设目标，长期稳定性需按实际分布与 WKC 核对。现场 1 ms 档曾触发掉线保护。50 ms 档每秒约更新 20 次，波形可用最大频率为 5 Hz。

## 三、按层排查

1. **电源和终端链**。测 EK1100 上方 Us，核对 24 V 标称电压、极性、模块顺序及末端盖。
2. **网卡与链路**。确认有线网卡直连 X1，用网页刷新，观察协商速率。可用 `Get-NetAdapter -Physical | Format-Table Name, Status, LinkSpeed, InterfaceGuid` 核对。普通 IP ping 无法证明 EtherCAT 通信成功。
3. **Npcap**。确认 WinPcap API 兼容模式。若安装时限制为管理员访问，从有相应权限的 PowerShell 启动。刷新列表，读「Npcap 不可用」及其具体错误。
4. **从站与 PDO**。查看检测到的从站顺序、AL 状态、PDO 分配、带符号表示和看门狗回读。接口占用时先关闭其他主站或停止项目的零值长测，再重试。
5. **网页或控制权**。对照控制台是否提示就绪，检查端口 8765 和 [本机仪表盘](http://127.0.0.1:8765/)。另一个标签页拥有控制权时，先用该页清零或正常关闭。若数据中断，读数用「—」标识；查实机状态和诊断区，避免将采样空缺当成 0 V。

## 四、停止日志与快速复测

在网页清零并断开，再到控制台按 Ctrl+C，或用窗口关闭按钮请求退出。日志中的 `confirmed`、`unknown` 和 `not_connected` 分别表示零值获 WKC 确认、结果未知及清理时总线已断开。总线断开时仍可查阅上一次连接的异常和统计。接线恢复后重新选网卡、手动连接，并保持零输出锁定完成检查。

如需独立于网页采集零值通信，先断开网页实机连接，再按 [开发、打包与发布](06-开发、打包与发布.md) 运行带网卡 GUID 的三分钟诊断。

## 五、中瑞桥接排查

1. **先查实机，再查 TCP**。确认 OP、实际/预期 WKC 一致，真实通道存在。未知模块、拓扑变化及重复 AO 映射会阻止发布。增加模块后 WKC 预期值可能不再为3，不应按旧数字判定失败。
2. **地址、端口与白名单**。网页8765端口不是中瑞协议端口。原版通常从6000起，扩展从7000起。同机用127.0.0.1，跨机用服务电脑局域网IP；白名单必须允许实际客户端IP。检查端口竞争、Windows防火墙和网络策略。
3. **控制归属**。开始监听不等于允许输出。网页授权后，原版首个连接或扩展申请者才能控制。同卡第二个原版连接会被拒绝；扩展只读连接不能写输出。控制端断开后须重新授权。
4. **报文和未实现功能**。在桥接最近事件或 bridge-events.jsonl 查最后操作码。原版未实现的数字、触发、UART等命令会关闭连接并清零，不能把缺少这些模块解释为网络掉包。已支持命令的参数错误保留原输出，在页面报告；扩展回复E1FF。
5. **数据速度和延迟**。逻辑200 kS/s不等于每秒200,000次独立测量。查看真实源速率、保持补点及源序号。native策略超额请求会拒绝；长时间无数据还可能是原版完整帧未填满。发送超时或积压上限会关闭对应连接。
6. **电压含义和接线**。双极性映射把原版码值0变成−10 V，网页清零才直接回到物理0 V。WKC正常只能证明过程数据处理回执，不能证明端子电压和回环导线；AI不随输出变化时，用已确认接线或万用表核对。

配置、量程公式、完整扩展字段和客户端示例见 [中瑞协议桥接与兼容说明](07-中瑞协议桥接与兼容说明.md)。公司软件的初始化序列尚未验证，协议测试通过后仍需实际软件联调。
